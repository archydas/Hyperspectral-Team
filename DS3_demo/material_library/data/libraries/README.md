Put your library files here (e.g. material_spectra.txt, soil_spectra.txt, hsdos_lib_spectra.txt,
samples_spectra_with_metadata.txt, ecostress_library_all_spectra.txt).
Every time the app starts, each file in this folder becomes its own library in the database
(already-imported files are recognised and skipped). Check the result at http://127.0.0.1:8000/api/startup_import
