# Hyperspectral Tools

A collection of tools for hyperspectral data processing, data aggregation, analysis, and visualization.

## Repository Overview

This repository contains two independent tools designed to support hyperspectral data workflows.

### 1. Hyperspectral Library and Data Aggregation

Located in the `Library/` directory.

This tool provides functionality for hyperspectral data handling, processing, aggregation, and related operations.

**Key Components:**
- Source code and modules
- Data management
- Database integration
- Plugins and supporting utilities
- Command-line and graphical interfaces

**Documentation:** [Library README](./Library/README.md)

### 2. Hyperspectral Viewer

Located in the `Viewer/` directory.

This tool provides visualization capabilities for hyperspectral data through its own application and supporting resources.

**Key Components:**
- Hyperspectral visualization
- Data exploration
- Supporting code and resources
- Application-specific documentation

**Documentation:** [Viewer README](./Viewer/README.md)

## Getting Started

Each tool is maintained independently and has its own installation instructions and dependencies.

To get started:

1. Clone this repository.
2. Navigate to the directory of the tool you want to use.
3. Open its respective `README.md` file.
4. Follow the installation and usage instructions provided for that tool.

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Hyperspectral-Tools.git
cd Hyperspectral-Tools
```
